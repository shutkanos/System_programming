## Часть 1: Знакомство с рабочим окружением

### 1. Создание программы на ассемблере

Файл сохранен по названию фамилии: `sandbox/Дегтярев.asm`

Компиляция и запуск:
```bash
cd sandbox
fasm Дегтярев.asm
chmod +x Дегтярев
./Дегтярев
```

### 2. Создание программы на C

Файл: `sandbox/С_version.c`

Компиляция и запуск:
```bash
cd sandbox
gcc С_version.c -o С_version
./С_version
```

### 3. Дизассемблирование программ

Результаты записаны в файл `sandbox/Disassemble`

Повторный запуск команд дизассемблирования:
```bash
cd sandbox

# Дизассемблирование C-программы через GDB
gdb -batch -ex 'file С_version' -ex 'disassemble main' > Disassemble

# Дизассемблирование ASM и C программ через objdump
objdump -d Дегтярев >> Disassemble
objdump -d С_version >> Disassemble
```

## Часть 2: Работа с файлами

Все команды записаны в файл `Work_files`. Для их повторного выполнения по шагам:

### Пункт 1: Создание папок
```bash
mkdir -p "Work/Лабораторная работа №1!"
mkdir -p "Work/Дегтярев Илья Сергеевич"
```

### Пункт 2: Установка прав (выполняется в самом конце)
```bash
chmod 770 "Work/Лабораторная работа №1!"
chmod 200 "Work/Дегтярев Илья Сергеевич"
```

### Пункт 3: Создание файлов
```bash
touch "Work/Text @1" "Work/Text \$2" "Work/Text  #3"
```

### Пункт 4: Запись текста без редактора
```bash
echo "Птица говорун отличается умом и сообразительностью!" > "Work/Text @1"
echo "Отличается умом, отличается сообразительностью..." >> "Work/Text @1"
```

### Пункт 5: Копирование содержимого
```bash
cat "Work/Text @1" > "Work/Text \$2"
```

### Пункт 6: Перемещение и копирование файлов
```bash
mv "Work/Text \$2" "Work/Лабораторная работа №1!/"
cp "Work/Text @1" "Work/Дегтярев Илья Сергеевич/"
```

### Пункт 7: Сжатие и архивирование
```bash
gzip -k "Work/Text @1"
gzip -k "Work/Text  #3"
tar -czf Work/MyAchiv.tar.gz "Work/Text @1.gz" "Work/Text  #3.gz"
```

### Пункт 8: Добавление текста в файл
```bash
head -n 1 "Work/Text @1" > "Work/Text  #3"
echo "Будь осторожен! Преступник вооружен!" >> "Work/Text  #3"
```

### Пункт 9: Обратный порядок строк
```bash
tac "Work/Дегтярев Илья Сергеевич/Text @1" > "Work/Дегтярев Илья Сергеевич/Result_one"
```

### Пункт 10: Переименование файла
```bash
mv "Work/Дегтярев Илья Сергеевич/Result_one" "Work/Дегтярев Илья Сергеевич/Result_two"
```

### Пункт 11: Список файлов по маске
```bash
ls "Work/Дегтярев Илья Сергеевич"/T* > "Work/Лабораторная работа №1!/Result_3" 2>/dev/null
```

### Пункт 12: Информация о системе
```bash
uname -a >> "Work/Лабораторная работа №1!/Result_3"
date >> "Work/Лабораторная работа №1!/Result_3"
```

### Финальная установка прав
```bash
chmod 770 "Work/Лабораторная работа №1!"
chmod 200 "Work/Дегтярев Илья Сергеевич"
```
